# TrashDrop Admin WebPortal

A comprehensive admin dashboard for managing the TrashDrop waste collection service.

## Features

- **User Account Management**: Profile settings, security options, and preferences
- **Pickup Request Management**: Filter, sort, and manage waste collection requests
- **Collector Management**: Assign and track waste collectors
- **Reporting and Analytics**: View performance metrics and statistics
- **Emergency Logout**: Quick logout functionality for security

## Technologies Used

- HTML5
- CSS3 (with Tailwind CSS framework)
- JavaScript (with jQuery)
- Responsive design for all device sizes

## Setup

1. Clone the repository
2. Open `trashdrop-admin-dashboard.html` in a web browser or serve using a local web server

## Project Structure

- `trashdrop-admin-dashboard.html` - Main application file
- `js/` - JavaScript files for functionality
- `modals/` - HTML components for modal windows and tabs
